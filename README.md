## Extensions Written By myself

* [`pi-tool-offloading`](./wutongyuonce/pi-tool-offloading)：上下文卸载扩展。把过大的工具结果写到 sidecar 文件里，减少后续轮次的上下文占用。
* [`pi-repomap`](./wutongyuonce/pi-repomap)：代码库感知工具，提供项目概览、符号映射和源码 / 测试文件配对能力。
