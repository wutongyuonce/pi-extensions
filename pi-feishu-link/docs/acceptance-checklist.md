# 实机验收清单（飞书沙箱租户）

> 对应 spec §10.3。代码级工作（M0–M8，170 测试全绿）已完成，以下为**需在真实飞书环境执行**的验收项。
> 每项完成后在「结果」列填 ✅ / ❌（附截图或日志）。发现的问题回飞书群或提 issue，附 `/support` 诊断包。

**环境**：飞书沙箱租户 · pi ≥0.82 · Node ≥22.19 · macOS/Linux

## 4. 可靠性与故障（R1/R2/R3）

| # | 步骤 | 预期 | 结果 |
| - | ---- | ---- | ---- |
| 4.1 | 拔网线 3min 后恢复 | 自动重连（指数退避）；恢复后收到「连接已恢复」通知；**验证开放问题 #2**：断连窗口消息是否被补收 | |
| 4.2 | 断连补收 | 恢复后机器人主动拉取窗口内消息（默认 5min） | 窗口内消息被处理（**验证开放问题 #4**） |
| 4.3 | kill -9 daemon 于回复发送中途 | 重启后 outbox 续投，**恰好一次**，飞书最终内容 = session.messages | |
| 4.4 | 模型卡死模拟（长任务） | 超时中止 + 队列解锁 + 飞书收到「超时已中止，请重试」 | |
| 4.5 | 流式卡 | 长回复时看到流式卡片增量更新；结束时定稿（**验证开放问题 #3** patch 频率） | |
| 4.6 | 分航道 | A 会话投递受阻时 B 私聊回复不被阻塞（可构造网络限制验证） | |
