从零开发：按“可验证的最小闭环”推进

别从 UI 或子代理开始。先让一条任务能创建、读取、更新、删除；每加一层能力都用测试锁住行为，再接回入口。

1

定义领域

复制 Task、状态枚举和 CRUD 测试；先只用内存 Map。

2

实现图规则

加入双向依赖、删除清边、排序；确定“警告但不拒绝”循环依赖的产品语义。

3

加持久化

实现 load / save / withLock，做并发与旧文件兼容测试。

4

接 Pi 工具

从 TaskCreate、List、Get、Update 开始；工具只做参数/文本适配。

5

接体验层

Widget、设置、提醒、自动清理；每个模块保持可独测。

6

最后接执行

先 ProcessTracker，再做带超时、取消与版本检查的子代理 RPC。

函数级代码地图

下面是“每个函数/方法在哪里、做什么、该在何时改”的索引；点击文件可回到真实源码逐行比对。

📄 src/types.ts

TaskStatus 与 Task 是全项目数据契约；TaskStoreData 是磁盘快照；BackgroundProcess 是进程记录。

📄 src/task-store.ts

sortById/Status/Recent/Oldest 定义排序；acquireLock/releaseLock/isProcessRunning 处理跨会话锁；normalizeTask 修复旧数据；load/save/withLock 封装持久化事务；create/get/list/update/delete/clearAll/snapshot/seed/deleteFileIfEmpty/clearCompleted 是完整仓库 API。

📄 src/reminder-cadence.ts

createCadenceState 初始化；resetCadenceState 切会话清零；onTurnStart 计回合；evaluateToolResult 判定是否应提醒；drainReminderForContext 一次性消费提醒。

📄 src/auto-clear.ts

trackCompletion 开始倒计时；checkAllCompleted 判断批量清理资格；resetBatchCountdown/reset 清状态；onTurnStart 真正删除到期任务。

📄 src/process-tracker.ts

track 订阅 stdout/stderr/close/error；getOutput 取快照；waitForCompletion 处理等待、超时、取消；stop 实现 SIGTERM → 5 秒 → SIGKILL；getProcess 暴露底层记录。

📄 src/tasks-config.ts

readTasksConfig 容错读 JSON；loadTasksConfig 合并全局默认值与项目覆盖；saveTasksConfig 只保存不同于全局的覆盖项。

📄 src/ui/task-widget.ts

truncateFromTop/Bottom 决定折叠方向；formatDuration/formatTokens 显示指标；setStore/setUICtx/setActiveTask/addTokenUsage/ensureTimer 更新运行状态；renderWidget/buildWidgetLines/update/dispose 负责安全渲染、注册、刷新和清理。

📄 src/ui/settings-menu.ts

openSettingsMenu 创建 SettingsList，并在每个 onChange 分支写项目配置；内置 SettingsPanel 是为把键盘输入转交给列表。

📄 src/index.ts

debug/textResult/intervalFor/sanitizeField/buildSystemReminder 是入口辅助函数；内部的 resolveStorePath/rpcCall/spawnSubagent/stopSubagent/checkSubagentsVersion/buildTaskPrompt/upgradeStoreIfNeeded/showPersistedTasks 分别管路径、RPC、兼容性、提示词和会话迁移。其余代码是 7 个工具与 Pi 事件的适配层。
