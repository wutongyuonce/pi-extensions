逐行定位

每次请求生成唯一回信地址，多个任务并发也不会串台。

超时必须取消监听，防止迟到回复继续占内存。

收到同一 ID 的回复后，无论成功或失败都完成 Promise。

最后才广播请求；接收方据此回到专属频道。

Aha：自动级联的关键不是“任务完成就开下一个”，而是 后继任务的全部 blockedBy 都已完成。这让图的分支可以并行推进。
