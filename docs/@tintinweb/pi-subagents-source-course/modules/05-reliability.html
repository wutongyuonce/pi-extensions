真实源码 · src/memory.ts
export function isUnsafeName(name: string): boolean {
  return name.includes("/") || name.includes("\\") || name === "." || name === "..";
}

export function isSymlink(filePath: string): boolean {
  try {
    return lstatSync(filePath).isSymbolicLink();
  } catch {
    return false;
  }
}
逐行定位
isUnsafeName：把路径分隔符和 . / .. 当作不安全输入，阻止目录穿越。
lstatSync：检查“链接本身”，不会跟随链接；这正是识别符号链接所需的语义。
catch → false：不存在的文件不是链接；调用者可继续按普通缺失文件处理。
⚠️
不要把“失败”压成一个状态

aborted、stopped、error、steered 的含义不同。保留差异，UI、通知与重试策略才不会说谎。
